# **App Name**: PathFinder Visualizer

## Core Features:

- Maze Generation: Generate a maze of specified dimensions, difficulty, and bias toward longer corridors using randomized algorithms.
- Algorithm Selection: Allow users to select between BFS (Breadth-First Search) and DFS (Depth-First Search) algorithms for pathfinding.
- Animated Traversal: Visualize the maze-solving process in real-time with animated highlighting of the path being explored. Use animation frame control for speed adjustment.
- Shortest Path Highlighting: After solving, highlight the shortest path found from start to finish.
- Obstacle generation tool (AI): LLM to intelligently decide how to generate an efficient configuration of obstacles given user adjustable parameters such as: number of obstacles, location restrictions, etc.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to suggest intelligence and problem-solving.
- Background color: Very light grey (#F0F0F0) to ensure a clear focus on the maze and pathfinding visualization.
- Accent color: Bright cyan (#00BCD4) to highlight the path being traversed during the animation, providing good contrast.
- Body and headline font: 'Inter', sans-serif, for clean readability.
- Use simple, geometric icons for algorithm selection, maze generation, and control buttons.
- Smooth transitions and animations for path highlighting to clearly indicate the traversal process.
